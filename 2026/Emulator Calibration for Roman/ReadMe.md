This folder contains parameter files for the paper:

* Title: _"Emulator-Assisted Calibration of a Semi-Analytic Galaxy Formation Model for the Roman Galaxy Redshift Survey"_
* Author(s): Robertson & Benson
* Publication year: 2026
* URLs:
  * [arXiv](https://arxiv.org/abs/2609.10680)
  * [NASA ADS](https://ui.adsabs.harvard.edu/abs/2026arXiv260910680R)
* Galacticus commit hash: [a8fd4a98520d4821b5b3d0551a13fa92ca100c90](https://github.com/galacticusorg/galacticus/commit/a8fd4a98520d4821b5b3d0551a13fa92ca100c90)
* Datasets commit hash: [18d9ec9d7111db34980c822eb24f4ae2aa76a943](https://github.com/galacticusorg/datasets/commit/18d9ec9d7111db34980c822eb24f4ae2aa76a943)

The emulator and calibration code used in this work is available in the [Galacticus-emulation](https://github.com/Andrew-Robertson/Galacticus-emulation) repo.

The complete Galacticus parameter files and the larger data products needed to reproduce the analysis will be deposited in a versioned Zenodo repository upon acceptance of the paper.

Parameter files for these models in [Andrew-Robertson/Galacticus-ParameterFiles](https://github.com/Andrew-Robertson/Galacticus-ParameterFiles) at tag [galacticemu-roman-grs-arxiv-v1](https://github.com/Andrew-Robertson/Galacticus-ParameterFiles/tree/galacticemu-roman-grs-arxiv-v1).
